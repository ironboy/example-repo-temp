# Getting started with the project
* You need to install a dotnet SDK (>=10.x).
* Do not forget to use an IDE with C# support.

# Checklist
1. Make sure the project runs when you write `dotnet run`
2. Familiarize yourself with the folder structure.
3. Try to write a small class of your own.
    * Start small!
    * Try to connect instances of the class with other classes using composition.
    * Make sure that the program continues to run.

### Don't forget
Have fun!
